### ধাপ ৩: ২৪/৭ ফ্রি হোস্টিংয়ে লাইভ করা (Render.com - 🌟 সেরা ও সুপার ফাস্ট)

যেহেতু এই সিস্টেমে AI ক্যাপচা বাইপাস লাইব্রেরি (`ddddocr`) রয়েছে, তাই **Render.com** এ এটি সবচেয়ে নির্ভরযোগ্যভাবে আজীবন ফ্রিতে চলে:

1. [render.com](https://render.com)-এ গিয়ে আপনার GitHub একাউন্ট দিয়ে **Sign In** করুন।
2. ড্যাশবোর্ডে **"New +"** বাটনে ক্লিক করে **"Web Service"** সিলেক্ট করুন।
3. আপনার GitHub রিপোজিটরিটি সিলেক্ট করে **"Connect"** চাপুন।
4. সেটিংস মিলিয়ে নিন:
   - **Name:** `bd-result-portal` (বা আপনার পছন্দমতো)
   - **Environment:** `Python 3`
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `gunicorn app:app`
   - **Instance Type:** `Free`
5. নিচে **"Deploy Web Service"** বাটনে চাপ দিন!
6. মাত্র ১-২ মিনিটের মধ্যে আপনার নিজস্ব লাইভ HTTPS লিংক পেয়ে যাবেন (যেমন: `https://bd-result-portal.onrender.com`), যা দিয়ে সারা দেশের যে কেউ ফলাফল দেখতে পারবে!
